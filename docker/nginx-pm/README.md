## Настройка https поверх http

>⚠️ Необходим белый ip
>⚠️ Необходима настройка перенаправления портов
>⚠️ Необходим домен (напр. reg.ru)

* Регистрируем на провайдере домена А-запись с субдоменом, напр. test.my-domain.ru (нужно некоторое время для обновления dns, можно проверять через например 2ip)
* Добавляем прокси-хост с адресом субдомена с переопределением на http, ip адрес устройсва и порт сервиса
* генерируем новый SSL сертификат через Let's Encrypt.
* сервис должен стать доступен по https.

## Дополнительные настройки для хоста

> Edit Proxy Host - Settings - Custom Nginx Configuration

### Настройка передачи больших файлов для хоста

```
client_max_body_size 0;
```

### Настройка таймаутов для хоста

```
proxy_read_timeout 600s;
proxy_send_timeout 600s;
proxy_connect_timeout 600s;
```
